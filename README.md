# reconocimiento-de-voz
Reconocimiento de voz en español e inglés para Windows (No necesita conexión a Internet)

## Características
- Reconocimiento de voz en español e inglés
- Funciona sin conexión a internet
- Temas claro y oscuro
- No requiere instalar Python ni dependencias adicionales

## Descarga

👉 [Descargar la última versión](../../releases/latest)

Descarga el archivo `.zip`, descomprímelo y ejecuta el instalador.
